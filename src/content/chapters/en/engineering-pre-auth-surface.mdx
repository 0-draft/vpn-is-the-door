## One request through the appliance

The appliance terminates TLS, then a web daemon reads the request and hands it to a handler. On FortiOS that daemon is `sslvpnd`, the process Fortinet names in its advisory for CVE-2022-42475 ([FG-IR-22-398](https://www.fortiguard.com/psirt/FG-IR-22-398)). Everything in the shaded zone runs at this point. The password, second factor and SAML assertion are checked only after it.

Of the {TOTAL} KEV-listed VPN and remote-access CVEs in the [door schedule](../../the-doors/), {PREAUTH} are reachable before login. The other {TOTAL - PREAUTH} were exploited in the wild chained behind one that is.

## Bug classes

Pre-auth code has to accept input from anyone, so it cannot rely on account limits or on who the sender is. In most SSL-VPN products the same web stack serves the login page and the logged-in portal.

Memory corruption is the largest group: buffer overflows, out-of-bounds reads and writes, one use-after-free. These bugs occur in memory-unsafe languages such as C and C++. CISA and the FBI list CVE-2025-0282 (Ivanti Connect Secure) and CVE-2023-6549 (Citrix NetScaler) as examples: "Threat actors frequently exploit these vulnerabilities to gain initial access to an organization's network and then move laterally to the wider network." That much of this code is old C inside one large web daemon is this site's inference from the bug classes and from lineages such as Pulse Secure to Ivanti; vendors do not publish it.

## Inventory the exposure

Only addresses and names that belong to you. Do not scan addresses you do not control, and get written permission before scanning a range a provider or vendor operates for you.

<div class="table-scroll" tabindex="0">

| Method | What it tells you | What it misses |
| --- | --- | --- |
| Asset register and contracts | Every internet-facing device, including boxes a vendor installed for remote maintenance. Osaka was entered through a catering vendor's appliance (p.45). | Devices nobody recorded |
| A scan of your own public IP ranges, by you or a contracted tester | Which ports answer, and which product and version the portal or TLS certificate reveals | Addresses outside the ranges you listed |
| Exposure search engines (Shodan, Censys) queried for your own ranges and domains | What outside scanners have already indexed about you, with history | Anything they have not crawled yet |
| Certificate transparency logs for your domains | Host names such as `vpn.example[.]com` that someone set up and forgot | Devices that use only an IP address |
| Vendor support portal | Model, serial number and the date support ends | Devices registered to a former contractor |

</div>

## Cutting the surface down

None of these changes fixes a vulnerable handler that stays enabled, so patching still applies.

  <PreauthLifecycle lang="en" variant="reduced" label="The same appliance as Fig. 5-2. A green bar marks a source-IP allow-list in front of the appliance. Clientless mode is crossed out as disabled and the management UI is crossed out as moved off the internet. No red route." />

<div class="table-scroll" tabindex="0">

| Change | What leaves the pre-auth zone | Basis |
| --- | --- | --- |
| Move the management interface to a separate management network | The administrative web UI and its API | CCCS: NMIs "should not be directly exposed to the Internet." |
| Allow the portal only from known source addresses, where users connect from fixed sites | Every handler, for everyone outside the list | Handa's appliance: "インターネット上のすべてのシステムからの接続が可能であった。" (technical volume, printed p.11). Fits partner and site-to-site access better than mobile workers. |
| Disable features you do not use: clientless web mode, unused SSO integrations, legacy protocol versions | The code behind those features | CCCS: "Deactivate any functionality that is not required." CVE-2026-24858 affected only devices with FortiCloud SSO enabled. |
| As a stopgap during an unpatched KEV, disable the SSL-VPN function | The whole portal | JPCERT/CC on CVE-2024-21762: "SSL VPN機能を無効にすることで本脆弱性の回避が可能です。" |

</div>
